# Sandbox Tools

The Sandbox Helper Tools lets you simulate transactions and test your integration before going live. You can try different payment scenarios to check system behavior and make sure payment flows work properly, without using real funds.

> **Available only in Sandbox Environment.** [Go to Sandbox Tools](https://dashboard.dana.id/sandbox/tools)
