# Transfer to Bank Inquiry Status

```http
POST /v1.0/emoney/transfer-bank-status.htm
```

This API is used for merchant to do inquiry status transfer to Bank transaction to DANA. For the easiest integration, use DANA's Libraries to implement  [Disbursement to Bank](https://dashboard.dana.id/api-docs-v2/llms/guide/disbursement/disbursement-to-bank.md).

## API Specification

| Field | Value |
| --- | --- |
| Expected Timeout | 4 second |
| SNAP Service Code | 00 |
| Accept | application/json |
| Content Type | application/json |

---

### Retry Mechanism

The following are the details of the retry mechanism in case merchant needs to initiate a retry process:

- Retry is a mandatory process.

- The maximum retry is 5 times.

- Using the following interval time: 5, 10, 20, 40, 60, till merchant's cut off (in seconds).
