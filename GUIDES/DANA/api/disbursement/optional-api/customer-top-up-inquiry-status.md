# Customer Top Up Inquiry Status

```http
POST /rest/v1.0/emoney/topup-status
```

This API is used for merchant to do inquiry status top up transaction to DANA. For the easiest integration, use DANA's Libraries to implement  [Disbursement to Balance](https://dashboard.dana.id/api-docs-v2/llms/guide/disbursement/disbursement-to-balance.md).

## API Specification

| Field | Value |
| --- | --- |
| Expected Timeout | 8 second |
| SNAP Service Code | 39 |
| Accept | application/json |
| Content Type | application/json |

---

### Retry Mechanism

The following are the details of the retry mechanism in case merchant needs to initiate a retry process:

- Retry is a mandatory process.

- The maximum retry is 5 times.

- Using the following interval time: 5, 10, 20, 40, 60, till merchant's cut off (in seconds).
