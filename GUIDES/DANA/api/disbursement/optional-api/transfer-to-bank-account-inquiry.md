# Transfer to Bank Account Inquiry

```http
POST /v1.0/emoney/bank-account-inquiry.htm
```

This API is used for merchant to do inquiry Bank account info via DANA. For the easiest integration, use DANA's Libraries to implement  [Disbursement to Bank](https://dashboard.dana.id/api-docs-v2/llms/guide/disbursement/disbursement-to-bank.md).

## API Specification

| Field | Value |
| --- | --- |
| Expected Timeout | 8 second |
| SNAP Service Code | 42 |
| Accept | application/json |
| Content Type | application/json |

## Request Body

| --- | --- | --- | --- | --- | --- | --- |

| 2 | customerNumber | String | Variable, 32 | Mandatory | - | Customer account number, in format 628xxx **Notes:** Fill with merchant business phone number |

| 4 | amount | Money | Variable | Mandatory | - | Amount. Contains two sub-fields:Value: Transaction amount, including the centsCurrency: Currency code based on ISO |
| 4.1 | amount.value | String | Variable, 19 | Mandatory | - | Value of amount. Following ISO-4217, for IDR the value includes 2 decimal digits separated with point e.g. ,IDR 10.000,- will be placed with 10000.00 |
| 4.2 | amount.currency | String | Variable, 3 | Mandatory | - | Currency |
| 5 | additionalInfo | JSON Object | Variable | Optional | - | Additional information |
| 5.6 | additionalInfo.fundType | String | Variable, 64 | Mandatory | - | Additional information of top up fund type. Possible values: `AGENT_TOPUP_USER_SETTLE`: used for disbursement to balance solution ` MERCHANT_WITHDRAW_FOR_CORPORATE`: used for disbursement to bank solution For this fund type, value always `MERCHANT_WITHDRAW_FOR_CORPORATE` |
| 5.7 | additionalInfo.externalDivisionId | String | Variable, 64 | Optional | - | Additional information of external division identifier. | 5.9 | additionalInfo.beneficiaryBankCode | String | Variable, 8 | Mandatory | - | Additional information of beneficiary Bank code, refer to Beneficiary Bank Code List |
| 5.10 | additionalInfo.beneficiaryAccountName | String | Variable, 64 | Optional | - | Additional information of beneficiary account name for validation purpose |
| 5.11 | additionalInfo.accountType | String | Variable, 64 | Optional | - | Additional information of account type |
