# Transfer to Bank

```http
POST /v1.0/emoney/transfer-bank.htm
```

This API is used for merchant to do transfer to Bank request via DANA. For the easiest integration, use DANA's Libraries to implement  [Disbursement to Bank](https://dashboard.dana.id/api-docs-v2/llms/guide/disbursement/disbursement-to-bank.md).

## API Specification

| Field | Value |
| --- | --- |
| Expected Timeout | 8 second |
| SNAP Service Code | 43 |
| Accept | application/json |
| Content Type | application/json |

---
## Request Headers

| No | Field | Type | Length | Required | Condition | Remarks |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | Content-type | String | Variable, 127 | Mandatory | - | Content type, value always `application/json` |
| 2 | Authorization | String | Variable, 2048 | Conditional | Y:= Signature option is symmetric approach | Contains bearer JWT token, which has been obtained from Authorization Token Request API |
| 4 | X-TIMESTAMP | String | Fixed, 25 | Mandatory | - | Transaction date time, in format YYYY-MM-DDTHH:mm:ss+07:00. Time must be in GMT+7 (Jakarta time) |
| 5 | X-SIGNATURE | String | Variable | Mandatory | - | Signature need to be generated with `symmetricSignature` or `asymmetricSignature` method |
| 6 | ORIGIN | String | Variable | Optional | - | Origin domain |
| 7 | X-PARTNER-ID | String | Variable, 36 | Mandatory | - | Unique identifier for partner was generated by DANA, or known as clientId |
| 8 | X-EXTERNAL-ID | String | Variable, 36 | Mandatory | - | Unique messaging reference identifier generated by merchant and should be unique within the same day |
| 9 | X-IP-ADDRESS | String | Fixed, 15 | Optional | - | IP address of the end user (customer) using IPv4 format |
| 11 | CHANNEL-ID | String | Variable, 5 | Mandatory | - | Device identification on which the API services is currently being accessed by the end user (customer) |

---
## Request Body

| No | Field | Type | Length | Required | Condition | Remarks |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | partnerReferenceNo | String | Variable, 64 | Optional | - | Unique transaction identifier in partner system for each transaction. **Note:** When retrying after a timeout or unexpected response, use the same partnerReferenceNo as in the original request |
| 2 | customerNumber | String | Variable, 32 | Optional | - | Customer account number, in format 628xxx |
| 3 | accountType | String | Variable, 25 | Optional | - | Customer account type |
| 4 | beneficiaryAccountNumber | String | Variable, 32 | Mandatory | - | Beneficiary account number |
| 5 | beneficiaryBankCode | String | Variable, 8 | Mandatory | - | Bank code for beneficiary account, refer to Beneficiary Bank Code List |
| 6 | amount | Money | Variable | Mandatory | - | Amount.Contains two sub-fields:Value: Transaction amount, including the centsCurrency: Currency code based on ISO |
| 6.1 | amount.value | String | Variable | Mandatory | - | Value of amount. Following ISO-4217, for IDR the value includes 2 decimal digits separated with point e.g. ,IDR 10.000,- will be placed with 10000.00 |
| 6.2 | amount.currency | String | Variable | Mandatory | - | Currency |
| 7 | additionalInfo | JSON Object | Variable | Optional | - | Additional information |
| 7.8 | additionalInfo.fundType | String | Variable, 64 | Mandatory | - | Additional information of top up fund type. Possible values: `AGENT_TOPUP_USER_SETTLE`: used for disbursement to balance solution ` MERCHANT_WITHDRAW_FOR_CORPORATE`: used for disbursement to bank solution For this fund type, value always `MERCHANT_WITHDRAW_FOR_CORPORATE` |
| 7.9 | additionalInfo.externalDivisionId | String | Variable, 64 | Optional | - | Additional information of external division identifier. (fundType: `MERCHANT_WITHDRAW_FOR_CORPORATE`)**Notes:** It is generally **optional**, but becomes **mandatory** if the `additionalInfo.chargeTarget` value is set to `DIVISION`. |
| 7.10 | additionalInfo.chargeTarget | String | Variable, 64 | Optional | - | Additional information of charge target. The values are: `null`, `DIVISION`, `MERCHANT`. **Note:** If the value is `DIVISION`, `externalDivisionId` will be mandatory. |
| 7.11 | additionalInfo.needNotify | Boolean | Variable | Optional | - | Additional information of flag result notification on transaction completed (result sync/async) |
| 7.12 | additionalInfo.beneficiaryAccountName | String | Variable, 64 | Optional | - | Additional information of beneficiary account name for validation purpose |
