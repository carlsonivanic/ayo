# Get Shop List

```http
POST /dana/merchant/shop/getShopList.htm
```

This API is used to obtain shop list. For the easiest integration, use DANA's Libraries to implement  [Shop](https://dashboard.dana.id/api-docs-v2/llms/guide/merchant-management/shop.md).
