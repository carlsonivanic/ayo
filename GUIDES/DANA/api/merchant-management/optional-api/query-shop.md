# Query Shop

```http
POST /dana/merchant/shop/queryShop.htm
```

This API is used to obtain information of shop information. For the easiest integration, use DANA's Libraries to implement  [Shop](https://dashboard.dana.id/api-docs-v2/llms/guide/merchant-management/shop.md).

## API Specification

| Field | Value |
| --- | --- |
| Expected Timeout | 3 second |

| Accept | application/json |
| Content Type | application/json |

## Request Body

| No | Field | Type | Length | Required | Condition | Remarks |
| --- | --- | --- | --- | --- | --- | --- |

| 3 | shopIdType | String | Variable, 11 | Mandatory | - | Shop identifier type, refer to shopIdType |
