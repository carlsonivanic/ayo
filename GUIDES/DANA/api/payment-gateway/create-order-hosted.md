# Create Order - Hosted Checkout

```http
POST /payment-gateway/v1.0/debit/payment-host-to-host.htm
```

This API allows merchants to create orders on the DANA for Payment Gateway functionality. For the easiest integration, use DANA's libraries to implement [Hosted Checkout](https://dashboard.dana.id/api-docs-v2/llms/guide/payment-gateway/hosted-checkout.md).

## API Specification

| Item | Value |
| --- | --- |
| Expected Timeout | `8 seconds` |
| SNAP Service Code | `54` |
| Accept | `application/json` |
| Content-Type | `application/json` |

## Idempotent Key & Usage Rules

Idempotent is controlled by **Idempotent Key** ( **merchantId** + **partnerReferenceNo**)

- If **Idempotent Key** has been created and the key information is consistent, then **Response code 2005400 (success)** will be returned.
- If **Idempotent Key** has been created but the key information isn't consistent, then **Response code 4045418 (inconsistent request)** will be returned.

### Notes

- **payMethod**: In sandbox, only BALANCE, CREDIT_CARD, DEBIT_CARD, VIRTUAL_ACCOUNT, NETWORK_PAY are available.
- **payOption**: In sandbox, only CARD, QRIS, BRI, PANIN, CIMB, MANDIRI, and BTPN are available.
- **validUpTo**: This must be set to a future time. In the **Sandbox** environment, the default expiration is 30 minutes.
