# Consult Pay

```http
POST /v1.0/payment-gateway/consult-pay.htm
```

This API is used to consult the list of payment methods or payment channels that the user has and can use for certain transactions or orders. For the easiest integration, use DANA's libraries to implement [Custom Checkout](https://dashboard.dana.id/api-docs-v2/llms/guide/payment-gateway/custom-checkout.md).

### externalStoreId

Check your external store ID in the [DANA Sandbox Submerchants Dashboard](https://dashboard.dana.id/sandbox/submerchants).

If you use QRIS or have outlets or stores under you, `externalStoreId` is mandatory. You can obtain `externalStoreId` from the [Create Shop API](https://dashboard.dana.id/api-docs-v2/llms/api/merchant-management/create-shop.md) or [DANA Sandbox Dashboard](https://dashboard.dana.id/sandbox/tools).
