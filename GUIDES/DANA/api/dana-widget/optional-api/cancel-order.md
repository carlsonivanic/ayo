# Cancel Order

```http
POST /v1.0/debit/cancel.htm
```

This is the API used to cancel the order from merchant's platform to DANA. For the easiest integration, use DANA's Libraries to implement [DANA Widget Binding](https://dashboard.dana.id/api-docs-v2/llms/guide/dana-widget/widget-binding.md) or [DANA Widget Non Binding](https://dashboard.dana.id/api-docs-v2/llms/guide/dana-widget/widget-non-binding.md).

## API Specification

| Item | Value |
| --- | --- |
| Expected Timeout | `8 second` |
| SNAP Service Code | `57` |
| Accept | `application/json` |
| Content-Type | `application/json` |

## Request Headers

| No | Field | Type | Length | Required | Condition | Remarks |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | `Content-Type` | String | Variable, 127 max | Mandatory | - | Content type, value always `application/json` |
| 2 | `X-TIMESTAMP` | String | Fixed, 25 max | Mandatory | - | Transaction date time, in format YYYY-MM-DDTHH:mm:ss+07:00. Time must be in GMT+7 (Jakarta time) |
| 3 | `X-SIGNATURE` | String | Variable | Mandatory | - | Signature need to be generated with `asymmetricSignature` method |
| 4 | `ORIGIN` | String | Variable | Optional | - | Origin domain |
| 5 | `X-PARTNER-ID` | String | Variable, 36 max | Mandatory | - | Unique identifier for partner was generated by DANA, or known as clientId |
| 6 | `X-EXTERNAL-ID` | String | Variable, 36 max | Mandatory | - | Unique messaging reference identifier generated by merchant and should be unique within the same day |
| 7 | `CHANNEL-ID` | String | Variable, 5 max | Mandatory | - | Device identification on which the API services is currently being accessed by the end user (customer) |

| No | Field | Type | Length | Required | Condition | Remarks |

| 1 | `originalPartnerReferenceNo` | String | Variable, 64 max | Mandatory | - | Original transaction identifier on partner system |

| 3 | `originalExternalId` | String | Variable, 36 max | Optional | - | Original external identifier on header message |
| 4 | `merchantId` | String | Variable, 64 max | Mandatory | - | Merchant identifier that is unique per each merchant |
| 5 | `subMerchantId` | String | Variable, 32 max | Optional | - | Sub merchant identifier, known as externalDivisionId must be registered in the DANA system before use. To register a new externalDivisionId, use the Create Division API |
| 6 | `reason` | String | Variable, 256 max | Optional | - | Cancellation reason |
| 7 | `externalStoreId` | String | Variable, 64 max | Optional | - | Store identifier to indicate to which store this payment belongs to, known as externalShopId must be registered in the DANA system before use. To register a new externalShopId, use the Create Shop API |

| 11 | `additionalInfo` | JSON Object | Variable, 0 max | Optional | - | Additional information |
