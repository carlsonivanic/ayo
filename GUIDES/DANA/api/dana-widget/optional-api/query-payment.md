# Query Payment

```http
POST /rest/v1.1/debit/status
```

This API is used to inquiry payment status and information from merchant's platform to DANA. For the easiest integration, use DANA's Libraries to implement [DANA Widget Binding](https://dashboard.dana.id/api-docs-v2/llms/guide/dana-widget/widget-binding.md) or [DANA Widget Non Binding](https://dashboard.dana.id/api-docs-v2/llms/guide/dana-widget/widget-non-binding.md).

### Notes

#### Signature Verification

DANA recommends partners verify the signature whenever they receive our virtual code response. This prevents virtual account number tampering and ensures the validity of the virtual account. Refer to the following steps:
1. Prepare the data of virtual account info as string to sign, the following is the example:
```json
{
"virtualAccountCode":"37218738131",
"virtualAccountExpiryTime":"2020-12-23T09:10:11+07:00"
}
```
2. Minify the JSON data.
```json
{"virtualAccountCode":"37218738131","virtualAccountExpiryTime":"2020-12-23T09:10:11+07:00"}
```
3. Decode the signature with base64.
4. Decrypt the signature using public key which is given by DANA.
5. Verify the correctness of the signature based on SHA-256 with RSA-2048 encryption signing against the string to sign.
