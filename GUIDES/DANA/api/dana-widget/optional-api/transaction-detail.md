# Transaction Detail

```http
POST /v1.0/transaction-history-detail.htm
```

## API Specification

| Item | Value |
| --- | --- |
| Expected Timeout | `8 second` |
| SNAP Service Code | `13` |
| Accept | `application/json` |
| Content-Type | `application/json` |
