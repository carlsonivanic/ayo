# Balance Inquiry

```http
POST /v1.0/balance-inquiry.htm
```

## API Specification

| Item | Value |
| --- | --- |
| Expected Timeout | `3 second` |
| SNAP Service Code | `11` |
| Accept | `application/json` |
| Content-Type | `application/json` |
