# Apply Token

```http
POST /v1.0/access-token/b2b2c.htm
```

## API Specification

| Item | Value |
| --- | --- |
| Expected Timeout | `8 second` |
| SNAP Service Code | `74` |
| Accept | `application/json` |
| Content-Type | `application/json` |

## Request Headers

| No | Field | Type | Length | Required | Condition | Remarks |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | `Content-Type` | String | Variable, 127 max | Mandatory | - | Content type, value always `application/json` |
| 2 | `X-TIMESTAMP` | String | Fixed, 25 max | Mandatory | - | Transaction date time, in format YYYY-MM-DDTHH:mm:ss+07:00. Time must be in GMT+7 (Jakarta time) |
| 3 | `X-CLIENT-KEY` | String | Variable | Mandatory | - | Unique identifier for partner was generated by DANA, or known as clientId |
| 4 | `X-SIGNATURE` | String | Variable | Mandatory | - | Signature can be generated by `asymmetricSignature` method only |
| 5 | `X-PARTNER-ID` | String | Variable, 36 max | Mandatory | - | Unique identifier for partner was generated by DANA, or known as clientId |

## Request Body

| No | Field | Type | Length | Required | Condition | Remarks |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | `grantType` | String | Variable, 64 max | Mandatory | - | Apply token request type. The values are `AUTHORIZATION_CODE` or `REFRESH_TOKEN` |
| 2 | `authCode` | String | Variable, 256 max | Conditional | Y:= grantType is `AUTHORIZATION_CODE` | An authorization code which the caller get from Deeplink Binding |
| 3 | `refreshToken` | String | Variable, 512 max | Conditional | Y:= grantType is `REFRESH_TOKEN` | This token is used for refresh session if existing token has been expired |
| 4 | `additionalInfo` | JSON Object | Variable | Optional | - | Additional information |

```json
X-PARTNER-ID: 82150823919040624621823174737537
Where:
stringToSign = client_ID + "|" + X-TIMESTAMP
{
"grantType": "AUTHORIZATION_CODE",

```

| No | Field | Type | Length | Required | Condition | Remarks |
| --- | --- | --- | --- | --- | --- | --- |

| 5 | `accessTokenExpiryTime` | String | Fixed, 25 max | Conditional | Y:= Successfully processed | Expiry time for access token was given to user, in format YYYY-MM-DDTHH:mm:ss+07:00. Time must be in GMT+7 (Jakarta time) |
| 6 | `refreshToken` | String | Variable, 512 max | Conditional | Y:= Successfully processed | This token is used for refresh session if existing token has been expired |
| 7 | `refreshTokenExpiryTime` | String | Fixed, 25 max | Conditional | Y:= Successfully processed | Expiry time for refresh token was given to user, in format YYYY-MM-DDTHH:mm:ss+07:00. Time must be in GMT+7 (Jakarta time) |
| 8 | `additionalInfo` | JSON Object | Variable, 0 max | Optional | - | Additional information |
| 9 | `additionalInfo.userInfo` | JSON Object | Variable, 0 max | Optional | - | Additional information of user. Contains publicUserId |
| 10 | `additionalInfo.userInfo.publicUserId` | String | Variable, 64 max | Optional | - | Static unique identifier for one user and one merchant |
