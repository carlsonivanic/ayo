# Finish Notify

```http
POST /v1.0/debit/notify
```

This API is used by DANA to notify merchants about the latest payment result for DANA Widget transactions. Use it together with [DANA Widget Binding](https://dashboard.dana.id/api-docs-v2/llms/guide/dana-widget/widget-binding.md) or [DANA Widget Non Binding](https://dashboard.dana.id/api-docs-v2/llms/guide/dana-widget/widget-non-binding.md) flows.

## API Specification

| Item | Value |
| --- | --- |
| Expected Timeout | `8 second` |
| SNAP Service Code | `56` |
| Accept | `application/json` |
| Content-Type | `application/json` |

## Response Codes

| No | Response Code | Response Message | Remarks | Partner Action |
| --- | --- | --- | --- | --- |
| 1 | `2005600` | Successful | Success to be processed | Mark Finish Notify process as Success |
| 2 | `5005601` | Internal Server Error | Unknown internal server failure, please retry the process again | Mark Finish Notify process as Pending. Retry periodically within 7 days |
| 3 | `Total timeout` | - | Total timeout, the client side does not get any responses from the server side (Can be due to network issue, server slowing down, and so on) | Do a retry maximum 3 attempts, if still fails mark Finish Notify process as Pending |
| 4 | `Unexpected response (Empty field/field does not exist/null response code)` | - | The server does not produce expected responses (Can be due to hardware failure, bugs, and so on) | - If the response code prefix are 202 and 5XX, mark Finish Notify process as Pending. - If empty field/field does not exist, mark Finish Notify process as Pending. |
