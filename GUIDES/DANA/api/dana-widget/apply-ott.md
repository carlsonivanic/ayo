# Apply OTT

```http
POST /rest/v1.1/qr/apply-ott
```

This API is used to generate a one-time token (OTT) from the access token obtained during the binding process. Use this API in the DANA Widget binding flow before redirecting the user to DANA's hosted checkout experience.

## API Specification

| Item | Value |
| --- | --- |
| Expected Timeout | `8 second` |
| SNAP Service Code | `49` |
| Accept | `application/json` |
| Content-Type | `application/json` |
